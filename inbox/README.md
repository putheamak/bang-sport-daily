# Your own articles

Put a Markdown file here, for example `inbox/2026-11-10-my-story.md`, written in English. The next run of
**Import my articles** (or the daily 6:07 run) will:

1. adapt it into Chinese and Russian,
2. find free photos for the `image_subjects` you list,
3. send it to you as a draft to approve, like any other story.

Each file is imported once. After importing, you can delete it or keep it.

The file format is described at the top of `sportnews/inbox.py`. The minimum is a header with a
`headline:` line between `---` lines, followed by the article text.
