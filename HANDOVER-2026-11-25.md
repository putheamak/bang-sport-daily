## Done this session (Facebook, recommendation #1)
- **Automatic Facebook Page posting is ON** (`publish.facebook: true`). A story posts to the Page only when the editor publishes it.
  - Secrets `FB_PAGE_ID` and `FB_PAGE_TOKEN` are set in GitHub.
  - The saved token is the editor's long-lived *user* token. `publishers.fb_page_token()` swaps it for the Page's own token automatically; the check shows token type PAGE, never expires, permissions `pages_manage_posts`, `pages_read_engagement`, `pages_show_list`.
  - Meta app: "Bang Sport Publisher", switched to **Live** on 25 Nov 23:44. In Development mode, posts made by the app were visible only to app roles (the editor). Privacy URL must be the address without .html (`https://bangsportdaily.com/en/privacy`), because Facebook rejects redirects.
- **Facebook Reels are ON** (`publish.facebook_reels: true`), built in `sportnews/reels.py`.
  - 12.5 s, 1080×1920, made only from our own material. Three scenes: headline card, then picture + summary, then "Full story".
  - Photos: only own cards, PD/CC0 or CC BY (with an on-screen credit). CC BY-SA photos are left out and replaced by a text card.
  - The English clip is uploaded to the Page. The Chinese and Russian clips are kept as GitHub run artifacts for 14 days, for Weibo/VK/Telegram by hand.
  - Fonts: Oswald/Inter for Latin and Cyrillic, Noto Sans CJK for Chinese. The workflows install it with `apt-get install fonts-noto-cjk ffmpeg`.
- **Reel sound is ON** (`publish.reel_sound: true`), built in `sportnews/sound.py`.
  - It is our own sound, made in code: the "Bang" audio logo plus a bed in one of three moods (news / combat / story, chosen by story type).
  - Loudness −16 LUFS. Approved by the editor.
- **Spacing:** Page posts and Reels go out at least 90 min apart, and never 00:00–06:00 Phnom Penh time. Later items are *scheduled* on the Page through the Graph API (`facebook_gap_minutes`, `facebook_quiet_hours`).
- **`facebook.yml` workflow modes:**
  - `post+reel`
  - `post`
  - `reel` (when the post was made by hand)
  - `redo-reel` (replaces a Reel that is still scheduled)
- **Sources:** Gemini "vertexaisearch" grounding redirect links are now resolved to the real page (`gnlinks.py`), or shown as the outlet's name without a link. 25 published stories had them; they are fixed as site rebuilds run.
- **AGENTS.md** now records the Facebook spacing rule and the "Create event" note. Facebook's own "Create event" suggestions get closed; never create events from stories.
