# How to give the AI your memo

| File | When it is used |
|---|---|
| `memos/general.md` | Every article (your standing experiences & views) |
| `memos/YYYY-MM-DD.md` | Only that day — e.g. `memos/2026-11-05.md` with today's angle, a match you attended, what to focus on |
| `memos/athletes/<slug>.md` | When that athlete's story is written — e.g. `memos/athletes/yao-ming.md` |

Daily memo can also include instructions, for example:

```
Focus: the Champions League night — I watched it live at 3am in Phnom Penh.
Tone: proud but honest about the defense.
Skip: anything about transfers.
```

Edit these from your phone on GitHub (pencil icon) before the 6:07 run.
